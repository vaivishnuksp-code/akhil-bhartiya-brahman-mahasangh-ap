## Production requirements
This package is a frontend prototype. A real public app should use a secure backend and admin authentication for:
- Member signup/login
- Technical Director approval
- Unique ID generation
- Photo/document upload and moderation
- State and district office-bearer management
- Gallery moderation
- Information/brochure publishing
- ID-card PDF/image generation
- Role-based permissions
- Audit trail and revocation
- Secure handling of sensitive member data

Do not use the demo approval control in a production deployment; replace it with authenticated server-side approval.
